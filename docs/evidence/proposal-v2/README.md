## 촬영과 실제 AI 호출의 구분

- 실제 AI 호출 원본: [ChatGPT 꽃 장식 응답](../base-profiles-v1/chatgpt-flower-audit.json). `gpt-6.1-sol`, 단일 응답 기록 14,807ms. 평균 지연이나 성공률을 뜻하지 않는다.
- 기본 프로필은 [Codex 이미지 초안 응답](../base-profiles-v1/image-draft-audit.json)을 적용했다. 민트 날개와 노란 목도리는 촬영용 시작 상태로 구성했다. 과거 화면의 전체 캐릭터 스냅샷과 완전히 동일하다고 주장하지 않는다.
- 별도 임시 로컬 데이터 폴더와 데모 서버에서 원본 꽃 장식 편집안을 그대로 재생했다. 이번 촬영은 새로운 모델 호출이 아니며, 사용자의 작업·보관함·계정 연결을 변경하지 않았다.
- 두 화면은 동일 브라우저 뷰포트 1280×720, 카메라 배율·방향으로 촬영했다. 원본 PNG를 보관하며 PDF에서 동일한 사각형 `(420, 47, 840, 374)`을 잘라 배치한다. 캐릭터를 이미지 편집·생성 도구로 수정하지 않았다.
- PDF의 인용 문장은 편집 요청의 요약이다. 원본 사용자 입력 로그로 제시하지 않는다.

## 파일

## 데이터 대조

기존 문서 속성과 기존 두 부품은 모두 유지됐다. 새 부품은 `pink_flower` 하나이며, 원본 AI 응답의 `upsert_part.part`와 동일하다. 꽃잎 5장과 꽃술을 나타내는 도형 6개가 포함됐다. 이 대조는 설정 보존 근거이며, 모든 각도에서의 시각적 완성도나 일반적인 명령 성공률을 입증하지 않는다.

보관함·AI 연결 창은 [기존 실제 UI 촬영](../character-library-v1/)을 사용한다. 471B·840B는 해당 폴더 `storage-sizes.json`의 캐릭터 설정 실측이며 메타데이터·편집 이력·이미지·렌더러를 제외한다.
