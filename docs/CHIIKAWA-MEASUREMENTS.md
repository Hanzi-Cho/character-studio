# 치이카와 실측 비교와 3D 반영 v3 · 2026-10-24

사용자 요구 R02.3: 머리·몸통 폭 관계는 유지하되 납작한 머리를 고친다. 수십 장의 레퍼런스를 검토하여 머리 가로/세로, 머리/몸통 폭, 팔다리·귀의 위치/크기/각도, 감정별 눈썹·눈·볼·입을 수치로 정리하고 실제 모델에 적용한다.

## 자료와 측정 방식

이번에 공식 상품 페이지 7곳에서 **38개 이미지 파일을 직접 확인**했다. 중복/유사 정면 6개와 우사기 단독 1개를 제외한 **31개 서로 다른 치이카와 포함 사진**을 관찰했다. 단체 사진은 인원수와 관계없이 1장이다. 앞선 [57개 스티커 컷 검토](CHIIKAWA-REFERENCE-REVIEW.md)는 별도 자료이며 57개 사진 파일로 부풀리지 않는다. ‘학습’은 시각 분석이며 모델 훈련을 뜻하지 않는다.

- [표준 봉제인형 S](https://chiikawamarket.jp/products/4589468435181): 정면, 사면, 생활 장면, 뒷면.
- [호와호와 서 있는 인형 S](https://chiikawamarket.jp/products/4582662910645): 정면, 크기가 다른 단체, 뒷면.
- [파크 푸와코로 S](https://chiikawamarket.jp/products/4571609359074): 정면과 단체, 열린 웃는 입.
- [묵직한 통통 인형](https://chiikawamarket.jp/products/4571609387930): 거의 같은 머리/몸통 폭, 뒷면. 턱 경계가 불명확하여 머리 높이 통계에서 제외.
- [포즈 인형](https://chiikawamarket.jp/products/4571609391890): 정면, 측면, 뒷면, 자세 변화.
- [도쿄미야게 앉은 인형](https://chiikawamarket.jp/products/4582662969889): 정면, 단체, 뒷면. 모자/리본이 머리 경계를 가려 높이 통계에서 제외.
- [키탄클럽 공식 얼굴 스퀴즈 5종](https://kitan.jp/products/okaonosqueeze_chiikawa/): 기본·울음·웃음·의욕·곤란. 얼굴 배치와 눈썹을 비교하기 적합한 큰 정면 사진.

전체 목록·제외 사유·개별 관찰은 [reference-inventory.csv](reference-data/reference-inventory.csv)에 있다. 12개 대표 사진의 원본 크기, 원본 URL, 수동 랜드마크, 계산된 비율은 [landmarks.json](reference-data/landmarks.json)에 보존했다. 원본 사진과 격자 검토본은 Git에서 제외된 `.data/research-v3/`에 있다. 앱 자산으로 복제하지 않는다.

모든 측정본은 원본 전체를 **600×600으로 리사이즈**했으며 잘라내지 않았다. 머리 폭은 귀를 제외한 최대 좌우 폭, 높이는 **정수리→턱/몸통 접합 경계**이다. 몸통 폭은 팔을 제외한 아래 몸통 단면이다. 600px 평면에서 경계와 중심을 수동 판독했다. 보통 **±5px**, 모자에 가려진 경계는 **±12px** 수준으로 보며 정확한 원작 설계도나 3D 스캔 치수로 해석하지 않는다. 각도는 짧은 선분이므로 약 ±5~10° 불확실성이 있다. 소수점은 계산 재현용이지 사진 판독의 정밀도를 뜻하지 않는다.

## 머리와 몸통 비교

| 독립 정면 표본 | 머리 폭 px | 머리 높이 px | 가로 100일 때 세로 | 머리/몸통 폭 |
| --- | ---: | ---: | ---: | ---: |
| 표준 S -01 | 355 | 266 | 74.93 | 1.420 |
| 호와호와 -01 | 352 | 260 | 73.86 | 1.578 |
| 파크 -01 | 350 | 264 | 75.43 | 1.452 |
| 포즈 -01 | 345 | 247 | 71.59 | 1.468 |
| 키탄 기본 | 535 | 419 | 78.32 | 해당 없음 |

독립 5개 표본의 머리 높이/폭 중앙값은 **0.7493**, 범위는 **0.7159~0.7832**다. 동일한 키탄 제품의 다른 표정 4장은 이 통계에 다시 넣지 않았다. 통통 인형은 폭 351px, 몸통 352px로 약 1.00이지만 머리 높이는 불명확하다. 앉은 모자 인형의 잠정 높이/폭 0.777은 통계에서 제외했다.

봉제인형은 상품 변형과 원근 때문에 몸통 폭 편차가 크다. 일반 봉제인형의 1.42~1.58을 그대로 채택하면 사용자가 이미 수정 요청한 큰 머리/좁은 몸으로 돌아간다. 따라서 **머리 높이는 사진 측정에 맞추고, 머리/몸통 폭 1.08은 현재 사용자 선호를 유지하는 설계값**으로 분리한다.

이전 모델의 논리적 머리 높이는 `(2.92−1.60)×0.86=1.1352`, 폭은 약 2.32여서 **세로/가로 약 0.49**였다. 전역 `root.scale.y=0.86`이 눈과 귀까지 눌렀다. 이번에는 이 압축과 숨겨진 `FACE_DROP`을 제거했다.

## 채택한 3D 수치

구현 정본은 [chiikawaRig.ts](../src/adapters/chiikawaRig.ts). 세계 좌표는 X=좌우, Y=위, Z=정면. 모델 기본값 기준이며 사용자 크기 편집은 그 뒤에 적용된다. 머리는 한 개의 연속 몸체 표면의 상부 구간으로 정의한다. 아래의 ‘턱’은 분리된 턱선 메시가 아닌 좌표 기준이다.

| 항목 | 3D 단위 | 머리 가로=100 기준 / 각도 |
| --- | --- | --- |
| 머리 가로×세로 | 2.32×1.76 | **100×75.86** |
| 머리 정수리 / 논리적 턱 | Y=3.10 / 1.34 | 얼굴 좌표의 위/아래 기준 |
| 몸통 최대 폭 | 2.15 | 92.67 → 머리:몸통 **1.079:1** |
| 몸통 아래/위 | Y=0.23 / 1.34 | 높이 47.84 |
| 머리 최대 깊이 | 약 1.624 | 70.0; 포즈 인형 측면 236px/정면 345px≈0.684를 참고한 3D 해석 |
| 귀 뿌리 | (±0.650, 2.924, −0.030) | X=±28.02, 정수리 아래 7.59 |

| 귀 중심 | 약 (±0.687, 3.038, −0.030) | 뿌리에서 귀의 로컬 Y로 0.12 이동한 결과 |

최대 폭은 샘플 기반 spline 메시에서 약간 달라질 수 있다. 자동 검증은 선언 상수만 비교하지 않고 **실제 버텍스와 월드 변환**에서 비율을 확인한다. 머리와 몸통은 둥글게 연결하며, 몸통 크기를 바꿔도 얼굴 가로·세로는 함께 늘어나지 않는다.

## 얼굴 좌표·디자인

정면 얼굴 좌표 `u=(x/머리폭)`, `v=(정수리에서 아래 거리/머리높이)`를 사용한다. 즉 `x=2.32u`, `y=3.10−1.76v`. 크기는 가로·세로 모두 **머리 폭**을 단위로 한다. 위치의 v 단위와 크기의 단위를 혼용하지 않는다.

| 부위 | 중심 (u,v) | 가로×세로 / 머리 폭 | 디자인 |
| --- | --- | --- | --- |
| 눈 | (±0.160, 0.510) | 0.125×0.130 | 짙은 둥근 타원, 위쪽 큰 반사광+아래 작은 반사광 |
| 위 반사광 | 눈 중심에서 (−0.006, −0.034) | 0.063×0.030 | 살짝 기운 흰 타원 |
| 아래 반사광 | 눈 중심에서 (+0.010, +0.031) | 0.047×0.020 | 위 반사광보다 작게 |
| 볼 | (±0.300, 0.610) | 0.170×0.115 | 분홍 타원, 짧은 사선 3개 |
| 기본 입 | (0, 약 0.670) | W 가로 0.140 | 둥근 W와 가운데 짧은 줄기, 아래 작은 곡선 |
| 기본 눈썹 | 바깥 u=±0.205 → 안쪽 ±0.125, v≈0.300 | 길이 약 0.080 | 짧은 곡선, 안쪽이 10° 높음 |

키탄 기본 얼굴에서 눈 중심 간격 184/535=0.344, 눈 크기 약 0.127×0.127, 볼 중심의 좌우 간격 약 0.589, W 입 폭 약 0.150을 확인했다. 일반 인형의 눈 간격은 약 0.29~0.30이었다. 구현 눈 간격 **0.32**, 볼 **0.60**, 입 **0.14**는 이 범위와 현재 모델을 조정한 설계값이다. 얼굴을 평면 스티커로 붙이지 않고 표면 깊이에 투영한 곡면 메시와 선으로 만든다.

## 감정별 레퍼런스와 수치

눈썹 각도의 부호: **바깥 끝→안쪽 끝으로 갈 때 안쪽이 높으면 +**, 낮으면 −. 좌우는 거울 대칭이다. 측정 각도는 JSON의 두 끝점으로 `atan2(outerY−innerY, abs(innerX−outerX))`를 계산한다. 곡선 중간 굴곡은 별도 형상이다.

| 표정 | 직접 대조한 레퍼런스 | 사진 관찰 → 구현 |
| --- | --- | --- |
| 기본 | [키탄 normal](https://kitan.jp/wp-content/uploads/2024/12/normal.jpg), 스티커 A-13 | 눈썹 +12.4°/+15.5° → **+10°, v=.300**. 둥근 눈과 W 입, 아래 짧은 곡선 |
| 웃음 | [키탄 nikkori](https://kitan.jp/wp-content/uploads/2024/12/nikkori.jpg), A-07 | 눈썹 +13.2°/+6.7° → **+8°, v=.285**. 감은 눈의 가운데 v=.467, 양끝 .490. 입 중심 v=.697, 크기 .082×.112, 흰 내부와 작은 분홍 아랫부분 |
| 슬픔 | [키탄 nakigao](https://kitan.jp/wp-content/uploads/2024/12/nakigao.jpg), A-10/C-21 | 사진의 울음 눈썹은 물결형이라 단일 기울기로 대표 불가. 스티커의 안쪽이 올라간 슬픔을 선택해 **+22°, v=.300**. 눈물 중심 (±.178,.615), 크기 .035×.088. W 아래 작은 찡그린 곡선 |
| 화남 | [키탄 yaruki](https://kitan.jp/wp-content/uploads/2024/12/yaruki.jpg), C-30 | 공식 명칭은 **의욕**이며 화남으로 오기하지 않는다. 안쪽으로 내려간 눈썹 −25.9°/−35.0°를 참고해 **−30°, v=.320**. W 아래 찡그린 입으로 화남을 해석 |

키탄의 [곤란 얼굴](https://kitan.jp/wp-content/uploads/2024/12/komatta.jpg)도 비교했다. 물결 눈썹과 떨리는 입은 슬픔/화남과 동일하지 않아 7번째 표정으로 추가하지 않았다. 6종은 사진을 그대로 복사한 공식 세트가 아니라 기존 요구에 맞춘 표정 해석이다. 표정 변경은 색·몸통·귀·장식·이름을 유지한다.

## 구현과 검증 근거

- `chiikawaRig.ts`: 수치·정규화 좌표·6개 눈썹 각도·연속 몸체 프로파일의 정본.
- `ChiikawaModel.ts`: 전역 세로 압축/얼굴 하강 보정 제거, 새로운 프로파일과 부위 좌표, 곡면 얼굴 6종 적용. 메시를 다시 만들지 않고 그룹 표시만 변경한다.
- `ThreeCharacterRenderer.ts`: 높아진 머리를 위한 시선 중심 Y=1.67. 드래그·방향키·정면 복원 유지.
- `tests/model.test.ts`: 월드 머리 세로/가로 0.74~0.78, 실제 눈·볼 좌표, 귀 연결/각도, 실제 눈썹 튜브 끝점의 6종 각도, 몸통 변경의 얼굴 보존, 표정 변경의 버퍼/색/장식 보존.
- 타입 검사·프로덕션 빌드·전체 **14개 자동 테스트 통과**. HTTP+실제 stdio MCP 회귀 포함.
- 로컬 브라우저에서 정면/마우스 드래그 사면/6표정 확인.
