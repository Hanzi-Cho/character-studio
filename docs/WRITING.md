# 문서 교정

제안서·도움말·제품 설명의 마지막 교정에 [Humanizer](../.agents/skills/humanizer/SKILL.md)를 사용한다. 설치 위치는 프로젝트의 `.agents/skills/humanizer`이며 다음 Codex 턴부터 자동 발견 대상이다. 이번 제안서는 설치된 지침을 직접 읽고 적용했다.

- 원본: https://github.com/blader/humanizer
- 버전: 3.1.0, 고정 커밋 `8c307f367c91bd974002f10f2be2965d642c13df`
- 라이선스: MIT, 원문 LICENSE 유지. 런타임 npm 의존성이나 외부 교정 API가 아닌 에이전트용 편집 스킬이다.
- 적용 순서: 사실·구현 근거 작성 → Humanizer 문장 교정 → 숫자·이름·URL·미검증 범위 대조 → PDF 전체 페이지 렌더 검수.
- 사실과 불확실성을 유지한다. 허구의 사용자 인터뷰, 성능 수치, 경험담을 추가하지 않는다. 지원 예정 기능을 구현 완료로 바꾸지 않는다.
- 추상적인 홍보 문구, 같은 뜻을 반복하는 문장, 독자가 알 필요 없는 작성 과정은 줄인다. 사용자가 무엇을 입력하고 무엇이 바뀌는지 구체적으로 쓴다.
- 코드·JSON·API 계약·출처 링크는 문체 교정 대상에서 제외한다. 사람이 쓴 것처럼 보이도록 사실을 조작하거나 AI 탐지 회피를 보장하지 않는다.

스킬 업데이트는 원본 변경 사항을 검토한 뒤 버전과 커밋을 함께 갱신한다.
