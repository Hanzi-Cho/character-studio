# Chiikawa Fidelity Improvement Strategy

2026-10-24 · 범위: 현재 치이카와 기본 모델의 조형 개선과 회귀 검증. 12종 카탈로그/새 부위 추가는 별도 확장 전략이다.

## 목표와 판정 원칙

10점은 **사용자가 선택한 머리/몸통 폭 방향을 유지하는 간결한 3D 스터디의 제작 수용 기준**이다. 모든 상품·원작 컷과 픽셀 단위로 동일하다는 뜻이나 객관적인 원작 유사도 점수가 아니다. 코드 테스트와 시각 판정을 분리하고, 아래 항목별 근거 없이 만점을 부여하지 않는다. 사용자 감상은 에이전트의 자기 평가와 별도다.

기준 자료는 기존 57개 스티커 그림·31개 고유 사진을 유지한다. 이번 조형의 주 기준은 [공식 Kitan 기본/감정 얼굴](https://kitan.jp/products/okaonosqueeze_chiikawa/), 몸통 폭과 짧은 팔다리는 [공식 통통 인형](https://chiikawamarket.jp/products/4571609387930)이다. 서로 다른 상품군을 평균내지 않고 얼굴/몸의 역할을 명시한다. 털 재질의 사진 복제가 아닌 매끄러운 입체 표면에 원작식 선을 표현한다.

## 수행 순서

1. 별도 검증 저장소에서 개선 전 화면을 새로 캡처한다. 실제 사용자 문서의 색·표정·이력을 보존한다.
2. 원본 얼굴 윤곽을 높이별로 관찰해 이마/볼/턱 제어점을 기록하고 연속 표면을 수정한다. 단순한 전체 확대/축소로 해결하지 않는다.
3. 반복 가능한 얼굴 shape/stroke 생성기를 만들고 반사광·입선·볼 경계를 교체한다. 소스 사진을 텍스처로 붙이는 대신 곡면에 정합되는 기하를 만든다.
4. 6종 표정을 다시 조정한다. 공통 위치 규칙을 유지하되 표정마다 눈의 외곽과 입·눈썹 곡선을 함께 바꾼다.
5. 같은 카메라의 전후 및 여러 방향을 관찰한다. 결함을 기록하고 추가 수정한다.
6. 실제 메시 측정, 회귀, UI/저장 동작을 확인하고 기준별 판정을 남긴다. 최종 수치·코드·증거와 기능 정의 문서를 함께 갱신한다.

### 현재 닮음에 대한 피드백

v3보다 볼 아래와 턱의 굴곡, 눈 반사광의 비정형성, W 입의 두께, 웃는 입과 우는 눈썹이 훨씬 가까워졌다. 정면만 읽히는 얼굴 장식에서 여러 방향에서도 피부를 따라가는 표현으로 개선됐다. 기본 표정과 웃음은 선택한 Kitan 자료의 핵심 특징을 안정적으로 읽을 수 있는 수준이다.

남은 차이는 **선택한 표현 방식**에서 온다. 상품 사진의 약한 좌우 비대칭·인쇄의 미세한 번짐·봉제 털과 주름을 재현하지 않았고, 깊이는 측면 자료를 참고한 회전체 해석이다. 머리/몸통도 단일 manifold로 융합한 제작용 메시가 아니다. 수작업 sculpt·리깅·애니메이션·출력용 topology가 목표가 되면 별도 제작 단계가 필요하다. 모든 공식 컷이 같은 비율은 아니므로 현재의 머리/몸통 약1.08은 사용자 방향을 계속 유지했다.

### 다음 기능으로 이어지는 순서

[12종/날개/표정/초기화/저장 전략](../features/character-catalog-and-customization-strategy.md): 템플릿과 인스턴스 v2 → 대표3종 → socket/부품 recipe → 공통 표정 recipe → 12종 확장 → 실제 AI/모바일. [전체 구조 리뷰](architecture-and-replaceability-review.md)에서 이를 막던 결합을 이미 분리했다. 초기화는 현재 선택한 기본 템플릿 버전으로 되돌리고, 저장 슬롯·사용자 recipe 라이브러리는 별도로 보존하도록 설계했다.
