Character Studio

마음에 드는 캐릭터를 불러와, 같은 3D 자산을 내 취향대로 계속 고치는 웹 도구

누가, 왜 쓰나요?

나노바나나·Sora로 이미지나 영상을 만들어 본 일반 사용자. 3D 편집 경험은 없지만, SNS·GitHub·커뮤니티에서 쓸 자기 캐릭터를 직접 꾸미고 싶은 사람을 첫 사용자로 삼습니다.

한 번 만든 모습에서 옷·표정·장식만 바꾸고, 돌려 보며 확인한 뒤 저장합니다. 다음에도 같은 캐릭터를 불러와 계절·기분·활동에 맞게 다시 고칠 수 있습니다.

프로필을 바꾸고 싶은 날, 저장한 캐릭터를 열고 “얼굴과 옷은 그대로, 머리에 작은 분홍 꽃을 달아줘”라고 말합니다. 옆·뒤까지 확인하고 원하는 각도의 이미지를 저장합니다. 마음에 들지 않으면 한 번에 되돌립니다.

실제 ChatGPT 연결 편집. 꽃은 사전 목록 선택이 아니라 꽃잎 5장·꽃술을 도형 6개로 구성한 결과입니다.

차별화하려는 경험

웹에서 가볍게 시작

기본 모델이나 저장 파일에서 출발합니다. AI 연결 후 참고 그림 1–4장의 특징으로 단순 3D 초안을 만듭니다.

수정한 부분을 확인하고 되돌리기

3D 설정과 장식을 구조화해 저장합니다. 요청하지 않은 속성은 유지하고 잘못된 명령은 적용하지 않습니다.

내 캐릭터를 이어서 사용

설정 JSON을 다시 열어 같은 자산을 편집하고, PNG 이미지는 프로필·커뮤니티에 활용합니다.

웹 접근이나 이미지→3D만으로 독점적 차별성을 주장하지 않습니다. 부분 수정·복구·재사용까지 이어지는 흐름이 일반 사용자에게 더 쉬운지 실제 사용 테스트로 검증합니다.

AI는 실행 코드 대신 편집 목록을 제안합니다. 전체 명령을 검사한 뒤 한 번에 적용하고, 검증 실패나 상태 충돌이면 기존 캐릭터를 보존합니다. 완성된 편집안만 적용하며, 기존 메시의 설정을 갱신합니다.

현재 확인한 것 / 앞으로 검증할 것

확인: 공개 데모, 실제 Codex 이미지→3D 초안, 공식 ChatGPT 로그인→새 장식 생성, 저장·되돌리기, 자동 시험 39개. 이미지 초안 1회 실행은 6.04초였으며 평균 성능은 아닙니다. 미검증: API 키 과금 호출, 자유 문장 성공률·시간 분포, 일반 사용자 수요, 모바일 실기기.

제품화 순서와 검증 목표

1  기본 자산과 시작 경험

기본 모델·이미지 초안 흐름을 다듬고 공개 대표 자산은 자체 디자인·허가 자산으로 준비.

2  AI 연결의 진입 부담 완화

웹 API 키·로컬 ChatGPT 연결을 제공. 계정 준비 없는 체험 경로와 사용량 한도는 비용·권한 검토 후 설계.

3  반복 편집 품질

자유 문장 30개·실패 시나리오 10개로 변경 정확도와 지연 측정. 비개발자 5명의 불러오기→수정→저장 과업 관찰.

4  확장

Blender 세부 수정, 여러 기본 캐릭터, 3D 파일 내보내기. MCP를 통한 다른 AI 도구 연결은 호스트별로 검증.

목표 일정: 10/25 제안서·기본 모델 확장 → 11/1까지 AI 연결·사용자 과업 검증 → 11/25까지 제출용 서비스와 시연 정리. 1인 개발이며 실제 검증 결과에 따라 범위를 조정합니다. 현재 AI 비용은 사용자 계정 부담이며, 운영자 제공 무료 체험·유료 저장·파츠 판매는 수요 확인 후 검토합니다.
