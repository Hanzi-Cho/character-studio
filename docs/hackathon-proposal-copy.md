# Character Studio 제안서 문안

2026-10-25 · 표지 포함 4쪽

대화로 만드는 나만의 3D 캐릭터

Character Studio

내 캐릭터를 저장해 두고 표정·옷·장식을 바꾸며 여러 모습으로 꺼내 쓰는 웹 스튜디오

누가, 왜 쓰나요?

나노바나나·Sora로 이미지나 영상을 만들어 본 일반 사용자. 3D 편집 경험은 없지만, SNS·GitHub·커뮤니티에서 쓸 자기 캐릭터를 직접 꾸미고 싶은 사람을 첫 사용자로 삼습니다.

프로필을 바꿀 때마다 내 캐릭터를 처음부터 만들 필요가 없도록, 마음에 드는 모습을 보관함에 남깁니다. 다음에도 불러와 계절·기분·활동에 맞는 표정과 장식으로 다듬고 원하는 각도로 꺼내 씁니다.

지금 바로 사용해 볼 수 있는 웹 데모

[웹 데모 열기  →  hanzi-cho.github.io/character-studio/](https://hanzi-cho.github.io/character-studio/)

설치·로그인 없이 41개 예문·3D 회전·내 캐릭터 보관함을 체험하세요.
자유 채팅은 본인 API 키로 연결합니다. ChatGPT 계정 연결은 로컬에서 지원합니다.

불러오기 → 부분 수정 → 회전 확인 → 보관함 → 다음에도 편집

기본 모델: 치이카와·우사기 선택과 여러 참고 이미지로 만드는 편집 가능한 3D 초안. 이미지는 색·비율·귀·얼굴 특징을 추정하는 참고로 사용하며, 정밀 메시 복원은 후속 범위입니다.

사용 동기와 대표 시나리오

프로필을 바꾸고 싶은 날, 저장한 캐릭터를 열고 “얼굴과 옷은 그대로, 머리에 작은 분홍 꽃을 달아줘”라고 말합니다. 옆·뒤까지 확인하고 원하는 각도의 이미지를 저장합니다. 마음에 들지 않으면 한 번에 되돌립니다.

편집 전 · 날개와 목도리를 꾸민 모습

편집 후 · 기존 모습에 꽃만 추가

실제 ChatGPT 연결 편집. 꽃은 사전 목록 선택이 아니라 꽃잎 5장·꽃술을 도형 6개로 구성한 결과입니다.

그때그때 바꾸고, 같은 캐릭터로 이어 쓰기

웹에서 가볍게 시작

기본 모델이나 저장 파일에서 출발합니다. AI 연결 후 참고 그림 1–4장의 특징으로 단순 3D 초안을 만듭니다.

내 캐릭터 보관함

이름 붙여 최대 50개를 보관합니다. 불러와 수정한 뒤 ‘변경 저장’, 이전 모습도 남기려면 ‘새 캐릭터로 저장’을 누릅니다.

작게 저장하고 다시 3D로

색·비율·표정·장식을 JSON 설정으로 보관합니다. 기본 캐릭터 471B, 셔츠·날개·웃음 적용본 840B. PNG는 프로필·커뮤니티에 쓰는 공유용 이미지입니다.

용량은 현재 예시의 공백 없는 UTF-8 JSON 실측이며 목록 메타데이터·이력·렌더러는 제외합니다. 보관함은 현재 브라우저에 저장됩니다. 사이트 데이터 삭제에 대비해 JSON을 내려받아 백업하세요.

연결해서 대화하고, 예문으로 먼저 체험

상단의 ‘내 AI 연결’에서 사용할 방식을 선택합니다. 아래는 실제 웹 데모의 연결 창입니다.

웹 데모 · 본인 API 키

1. ‘내 AI 연결’을 엽니다.
2. 본인 OpenAI API 키를 입력합니다.
3. 전송·사용료 동의 후 ‘API 키 연결’.
4. 사용 모델을 고르고 창을 닫습니다.

로컬 실행 · ChatGPT 계정

같은 창에서 ‘Continue with ChatGPT’를 누릅니다. 공식 화면의 로그인·권한 동의를 마치고 돌아와 모델을 선택합니다. 지원 플랜과 이용 한도가 적용됩니다.

[로컬 실행 방법 보기 ↗](https://github.com/Hanzi-Cho/character-studio#내려받아-체험하기--codex-불필요)

연결 후 하단 채팅에 요청

“얼굴과 옷은 그대로, 머리에 작은 분홍 꽃을 달아줘.”
결과를 돌려 보고, 마음에 들면 보관함에 저장합니다. + 버튼으로 참고 이미지도 첨부할 수 있습니다.

API 이용료는 본인 계정 부담이며 ChatGPT 구독과 별도입니다. 키·토큰은 실행 중인 메모리에만 유지합니다. 웹 새로고침·로컬 서버 재시작 시 해당 연결을 다시 해야 합니다. 채팅·현재 설정·선택한 이미지가 AI로 전송됩니다.

AI 없이도 바로 체험

추천 문장 옆 새로고침 → ‘바로 적용’. 또는 아래 예문을 채팅에 그대로 입력하세요.

하늘색 셔츠와 작은 하얀 날개를 달고 웃는 표정으로

41개 예문은 미리 저장한 편집 명령을 적용하므로 로그인·API 키·모델 호출이 필요 없습니다. 색·옷·장식·표정 변경, 회전, 되돌리기와 보관함을 체험할 수 있습니다. 예문을 벗어난 자유 채팅과 이미지 초안은 AI를 연결해 사용합니다.

다음에도 같은 모습에서 시작

‘내 캐릭터 보관함’ → 이름 입력 → 저장. 다음 접속 때 ‘불러오기’로 이어서 수정합니다. 보관본의 JSON은 백업용으로 내려받고 + 버튼으로 다시 가져올 수 있습니다. PNG에는 편집 설정이 포함되지 않습니다.

AI의 JSON 편집안 → JSON.parse → ENUM·수치·현재 버전 검증 → 변경 적용 순서입니다. set(속성 변경), upsert_part(장식 추가·수정), remove_part(장식 삭제) 등 허용 명령만 실행합니다. 전체 계획을 검사한 뒤 한 번에 적용하므로 검증 실패나 충돌이면 기존 캐릭터를 보존합니다.

빠른 반영: 전체 3D를 새로 생성하지 않고 설정이 달라진 부위를 갱신합니다. 보관함도 설정으로 다시 그립니다. AI 응답을 기다리는 시간과 화면 갱신 시간은 별개이며, 예문은 AI 응답 대기가 없습니다.

제품화 순서와 검증 목표

1  기본 자산과 시작 경험

기본 모델·이미지 초안 흐름을 다듬고 공개 대표 자산은 자체 디자인·허가 자산으로 준비.

2  AI 연결의 진입 부담 완화

웹 API 키·로컬 ChatGPT 연결을 제공. 계정 준비 없는 체험 경로와 사용량 한도는 비용·권한 검토 후 설계.

3  반복 편집 품질

자유 문장 30개·실패 시나리오 10개로 변경 정확도와 지연 측정. 비개발자 5명의 불러오기→수정→저장 과업 관찰.

4  확장

Blender 세부 수정, 여러 기본 캐릭터, 3D 파일 내보내기. MCP를 통한 다른 AI 도구 연결은 호스트별로 검증.
