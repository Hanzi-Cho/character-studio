# Character Studio 제안서 문안

2026-10-25 · 표지 포함 6쪽

대화로 만드는 나만의 3D 캐릭터

Character Studio

내 캐릭터를 저장해 두고 표정·옷·장식을 바꾸며 여러 모습으로 꺼내 쓰는 웹 스튜디오

누가, 왜 쓰나요?

나노바나나·Sora로 이미지나 영상을 만들어 본 일반 사용자. 3D 편집 경험은 없지만, SNS·GitHub·커뮤니티에서 쓸 자기 캐릭터를 직접 꾸미고 싶은 사람을 첫 사용자로 삼습니다.

프로필을 바꿀 때마다 내 캐릭터를 처음부터 만들 필요가 없도록, 마음에 드는 모습을 보관함에 남깁니다. 다음에도 불러와 계절·기분·활동에 맞는 표정과 장식으로 다듬고 원하는 각도로 꺼내 씁니다.

[웹 데모 열기  →  hanzi-cho.github.io/character-studio/](https://hanzi-cho.github.io/character-studio/)

설치·로그인 없이 41개 예문·3D 회전·내 캐릭터 보관함을 체험하세요.
자유 채팅은 본인 API 키로 연결합니다. ChatGPT 계정 연결은 로컬에서 지원합니다.

불러오기 → 부분 수정 → 회전 확인 → 보관함 → 다음에도 편집

기본 모델: 치이카와·우사기 선택과 여러 참고 이미지로 만드는 편집 가능한 3D 초안. 이미지는 색·비율·귀·얼굴 특징을 추정하는 참고로 사용하며, 정밀 메시 복원은 후속 범위입니다.

실제 AI 편집 사례 · 기존 응답을 현재 화면에서 재현

편집 요청 요약

“얼굴과 몸 비율, 민트색 날개와 노란 목도리는 그대로 두고, 머리 위에 작은 연분홍 꽃을 달아줘.”

편집 전 · 날개와 목도리를 꾸민 모습

편집 후 · 분홍 꽃잎 5장과 노란 꽃술

유지된 설정

기본 모델·얼굴·몸 비율·표정·날개·목도리. 기존 값·장식이 유지됐는지 전후 JSON으로 확인했습니다.

추가된 설정

AI가 새 장식 pink_flower를 구성했습니다. 꽃잎과 꽃술은 위치·회전·크기를 가진 도형 6개입니다.

색을 바꾸는 명령을 넘어, 새 부품의 구성을 제안

꽃 모양을 고정된 메뉴에서 고르는 대신, AI가 기본 도형의 배치와 크기를 정해 편집 명령으로 돌려줍니다. 현재는 제한된 도형 조합으로 만든 장식이며, 임의의 정밀 3D 메시를 생성하는 기능은 아닙니다.

공식 ChatGPT 연결 기록: gpt-6.1-sol, 응답 14.8초(단일 사례). 평균 속도·성공률은 아직 측정하지 않았습니다. 위 이미지는 같은 AI 응답을 별도 데모 설정에 적용해 동일한 카메라 배율로 촬영한 화면입니다.

[실제 AI 응답 JSON과 편집 전후 설정 확인 ↗](https://github.com/Hanzi-Cho/character-studio/tree/main/docs/evidence/proposal-v2)

한 번 만든 캐릭터, 다음에도 이어서

첫 사용자는 이미지·영상 AI를 써 봤지만 3D 편집 도구는 낯선 사람입니다. 결과물을 다시 만드는 부담을 줄이고, 마음에 든 캐릭터의 일부만 바꾸는 흐름에 집중합니다.

프로필을 바꿀 때

얼굴은 유지하고 표정·옷·장식을 바꿔 SNS나 GitHub 프로필용 PNG를 저장합니다.

커뮤니티에서 활동할 때

같은 캐릭터에 계절이나 활동에 맞는 소품을 더해 여러 모습으로 사용합니다.

다시 편집할 때

보관함에서 불러와 이어서 수정합니다. 원본을 남기고 새 버전으로 저장할 수도 있습니다.

내 캐릭터 보관함

이름 붙여 최대 50개 저장
불러오기 → 수정 → 변경 저장
새 버전은 ‘새 캐릭터로 저장’
JSON 백업·가져오기·삭제

작게 저장하고 다시 3D로

471 B  기본 캐릭터
840 B  셔츠·날개·웃음 적용본

색·비율·표정·부품의 설정을 저장하고, 불러올 때 렌더러가 다시 그립니다. PNG는 공유용 이미지, JSON은 이어서 편집하기 위한 파일입니다.

위 용량은 공백 없는 UTF-8 캐릭터 JSON의 실측입니다. 보관함 메타데이터·편집 이력·렌더러·이미지는 제외하며, 모든 3D 모델이 이 용량으로 저장된다는 뜻은 아닙니다. 보관함은 현재 브라우저에만 저장되므로 JSON 파일을 백업하세요.

확인할 수요 가설

완성 이미지 한 장보다, 정체성을 유지한 채 반복 편집할 수 있는 캐릭터가 다시 방문할 이유가 될 것으로 봅니다. 이 수요는 아직 사용자 조사로 입증되지 않았으며, 저장 후 재편집 과업으로 확인할 계획입니다.

연결해서 대화하고, 예문으로 먼저 체험

상단의 ‘내 AI 연결’에서 사용할 방식을 선택합니다. 아래는 실제 웹 데모의 연결 창입니다.

웹 데모 · 본인 API 키

1. ‘내 AI 연결’을 엽니다.
2. 본인 OpenAI API 키를 입력합니다.
3. 전송·사용료 동의 후 ‘API 키 연결’.
4. 사용 모델을 고르고 창을 닫습니다.

로컬 실행 · ChatGPT 계정

같은 창에서 ‘Continue with ChatGPT’를 누릅니다. 공식 화면의 로그인·권한 동의를 마치고 돌아와 모델을 선택합니다. 지원 플랜과 이용 한도가 적용됩니다.

[로컬 실행 방법 보기 ↗](https://github.com/Hanzi-Cho/character-studio#내려받아-체험하기--codex-불필요)

연결 후 하단 채팅에 요청

“얼굴과 옷은 그대로, 머리에 작은 분홍 꽃을 달아줘.”
결과를 돌려 보고, 마음에 들면 보관함에 저장합니다. + 버튼으로 참고 이미지도 첨부할 수 있습니다.

API 이용료는 본인 계정 부담이며 ChatGPT 구독과 별도입니다. 키·토큰은 실행 중인 메모리에만 유지합니다. 웹 새로고침·로컬 서버 재시작 시 해당 연결을 다시 해야 합니다. 채팅·현재 설정·선택한 이미지가 AI로 전송됩니다.

AI 없이도 바로 체험

추천 문장 옆 새로고침 → ‘바로 적용’. 또는 아래 예문을 채팅에 그대로 입력하세요.

하늘색 셔츠와 작은 하얀 날개를 달고 웃는 표정으로

41개 예문은 미리 저장한 편집 명령을 적용하므로 로그인·API 키·모델 호출이 필요 없습니다. 색·옷·장식·표정 변경, 회전, 되돌리기와 보관함을 체험할 수 있습니다. 예문을 벗어난 자유 채팅과 이미지 초안은 AI를 연결해 사용합니다.

다음에도 같은 모습에서 시작

‘내 캐릭터 보관함’ → 이름 입력 → 저장. 다음 접속 때 ‘불러오기’로 이어서 수정합니다. 보관본의 JSON은 백업용으로 내려받고 + 버튼으로 다시 가져올 수 있습니다. PNG에는 편집 설정이 포함되지 않습니다.

말 한마디가 3D 편집이 되기까지

AI는 변경안을 제안하고, 서비스는 허용된 명령만 실행합니다. 아래는 현재 코드의 처리 흐름입니다.

01  입력

문장·현재 설정·선택 이미지

“꽃만 달아줘”와 현재 부품 정보를 함께 전달합니다. 기존 설정은 유지할 대상이 됩니다.

02  AI 해석

의도 → JSON 편집안

꽃잎의 색·위치·크기를 정하고 upsert_part 명령을 만듭니다. 여러 수정을 하나의 계획에 담을 수 있습니다.

03  파싱

JSON.parse

응답 문자열을 구조화된 데이터로 읽습니다. 실행 코드나 임의 스크립트를 실행하지 않습니다.

04  검증

ENUM·범위·버전 검사

명령·표정·도형 종류는 허용 목록에서 선택합니다. 크기·색·부품 수와 현재 문서 버전을 확인합니다.

05  상태 반영

검증한 계획을 한 번에 적용

set / upsert_part / remove_part 등으로 설정을 갱신합니다. 오류·충돌이면 기존 상태를 보존합니다.

06  렌더링

변경 부위 갱신·되돌리기

Three.js가 설정을 3D 화면으로 반영합니다. 사용자가 회전해 확인하고 PNG·JSON·보관함으로 남깁니다.

왜 변경이 빠르게 보이나요?

전체 메시를 다시 생성하지 않고 장면과 기본 도형을 재사용해 달라진 속성·부품을 갱신합니다. AI 해석 대기와 화면 반영은 다른 단계입니다. 41개 예문은 저장된 명령을 사용하므로 AI 대기가 없습니다.

모델과 렌더러를 교체할 수 있는 구조

React UI → 편집 서비스·명령 스키마 → AI·저장·렌더링 어댑터로 나눴습니다. Meta 모델 API와 Blender는 같은 편집 흐름에 연결할 후속 대상이며, 현재 연동 완료 기능은 아닙니다.

[명령 계약·검증·실제 AI 연동 문서 ↗](https://github.com/Hanzi-Cho/character-studio/blob/main/docs/features/codex-character-editing.md)

동작하는 데모에서, 다시 쓰는 서비스로

현재 확인한 구현과 다음 검증

공개 웹 데모, Codex의 참고 이미지 → 3D 초안, 공식 ChatGPT 연결 → 새 장식 생성, 보관함 재열기·수정·JSON 복구를 확인했습니다. 자동 시험은 44개가 통과한 상태입니다. API 키의 유료 정상 호출, 폭넓은 자유 명령 성공률, 일반 사용자 수요, 모바일 실기기는 추가 검증이 필요합니다.

본선까지 확인할 세 가지 목표

편집 정확도

자유 문장 30개로 요청 수행·유지 조건·실패 이유·응답 시간을 기록합니다. 목표는 두 조건을 모두 만족하는 27/30건 이상입니다.

실패와 복구

오류·충돌 등 10개 시나리오에서 원본을 보존하고, 저장·내보내기·재가져오기로 같은 설정을 복원하는지 확인합니다.

비개발자 사용성

5명에게 불러오기 → 수정 → 저장 → 다시 편집 과업을 맡깁니다. 목표는 4명 이상이 도움 없이 완료하는 것입니다.

위 숫자는 앞으로 확인할 수용 목표이며 조사·평가 결과가 아닙니다. 예문 적용 성공은 AI 성공률에 포함하지 않습니다.

개선 순서 · 1인 개발 범위에 맞춰 단계적으로

1  출시 준비

자체 디자인·허가 자산 확보와 코드·이미지·모델 이용 조건 점검. AI 연결 안내, 백업·삭제, 접근성·모바일·오류 복구 검증.

2  반복 편집 품질

얼굴·체형 등 유지할 속성과 변경할 부위를 명시. AI가 여러 시점의 렌더를 확인하고 어색한 부품을 수정하는 검증 루프 개발.

3  모델링 범위 확장

Blender 세부 수정, 다른 기본 캐릭터와 3D 파일 내보내기. Meta 모델 API는 접근 승인 후 평가·연결.

11/1까지 AI 연결·사용자 과업을 검증하고 11/25까지 제출용 서비스·시연을 정리하는 것이 목표입니다. 운영자 제공 AI 체험은 지원 크레딧·사용량 한도·호출당 비용을 확인한 후 도입을 검토합니다.
