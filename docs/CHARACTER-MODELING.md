# 기본 치이카와 모델 수정 · 2026-10-24

> 이 문서는 이전 모델 변경 이력이다. 현재 v4의 수치/형상 정본은 [초기 캐릭터 렌더 생성](features/initial-character-render-generation.md), 개선 결과는 [v4 개선 기록](reviews/chiikawa-fidelity-improvement.md)을 따른다.

## 현재 모델 · 3차 실측 교정

[실측 비교와 전체 수치](CHIIKAWA-MEASUREMENTS.md)가 현재 정본이다. 이번 공식 사진 38파일 중 중복/다른 캐릭터를 제외한 31장을 관찰하고, 12장에 좌표를 남겼다. 독립 정면 5개 표본의 머리 세로/가로 중앙값은 0.7493이다.

- 머리 가로×세로 2.32×1.76 (100×75.86), 머리/몸통 최대 폭 약 1.08:1. 전역 세로 압축 0.86과 FACE_DROP을 제거했다.
- 귀 0.34×0.40, 바깥 기울기 18°. 눈·볼·입은 머리의 정규화 좌표로 배치한다. 6개 눈썹 각도는 +10/+8/+22/−30/0/0°다.
- `chiikawaRig.ts`가 부위 좌표·크기·각도·몸체 프로파일 정본이며 모델과 얼굴 표면이 같은 기준을 쓴다.
- 타입/빌드 및 자동 테스트 14개 통과. 정면·드래그 사면·6표정·390×844 화면 확인, 브라우저 오류 없음. 실제 모바일 터치와 사용자 닮음 평가는 미검증.
- 실제 4317 작업 공간의 분홍색 설정을 보존했다. 흰색 모델 검증은 별도 4318 데이터에서 실행했다.

현재 캡처: `docs/evidence/chiikawa-measured-*-v3.jpg`. 아래 1·2차 내용은 당시 이력이며 현재 치수와 혼합하지 않는다.

## 이전 모델 · 비율 수정 2차와 6종 표정

최신 사용자 정정(얼굴 폭이 몸통보다 아주 약간 넓음)이 아래 1차 참조 선택보다 우선한다. [57개 그림 검토 기록](CHIIKAWA-REFERENCE-REVIEW.md)에 출처·선별 위치·관찰/제외 기준을 남겼다.

- 얼굴/몸통 최대 폭 약 1.08:1. 한 개의 연속 spline lathe로 목의 잘록함과 머리/몸 경계선을 없앴다. 전체 세로 비율을 낮추고 얼굴을 약간 아래로 배치했으며 팔과 발을 짧고 둥글게 수정했다.
- 몸 비율 편집은 같은 vertex buffer의 하부를 연속적으로 변형한다. 얼굴 쪽 폭은 고정하고 몸 높이에 맞춰 얼굴 그룹도 이동한다. 표정 편집은 몸 geometry를 다시 업로드하지 않는다.
- 기본/웃음/슬픔/화남/놀람/졸림 6종 시안과 선택 버튼을 제공한다. 눈/눈썹/입/눈물만 변경하며 몸·귀·볼 색/크기·이름·장식은 그대로 유지한다.
- UI 선택, 한국어 채팅, HTTP patch, stdio MCP가 같은 expression enum과 revision 검증을 쓴다. 기존 gentle/happy/surprised 저장 파일은 그대로 읽힌다. 새 표정을 저장한 파일은 구버전 앱에서 지원하지 않으므로 구버전으로 되돌릴 때 기본/웃음/놀람 중 하나로 내보내야 한다.
- 사용자의 현재 분홍색 저장 상태(revision 16)를 유지했다. 흰색 기본 모델과 수정/되돌리기 검증은 4318의 별도 임시 데이터 폴더에서 실행했다. 4317은 사용자가 계속 사용할 작업 공간이다.
- 타입/빌드 및 자동 테스트 12개, PC 1280×720의 6종 실제 화면, 390×844 반응형/수정/회전/키보드 선택, 저장 후 새로고침/되돌리기 확인. 실제 휴대폰 터치·성능은 미검증.

현재 캡처: `docs/evidence/chiikawa-proportions-v2.jpg`, `expression-{happy,sad,angry,surprised,sleepy}.jpg`, `expressions-mobile-390.jpg`, `expressions-mobile-rotated.jpg`.

## 이전 모델 · 1차 수정 이력

아래 내용과 `chiikawa-remodel-*` 캡처는 1차 구현 이력이며 현재 비율/연속 표면 구조를 설명하지 않는다.

사용자가 이 대화에 제공한 3장(정면 3D 모델, 작은 흰색 입체 캐릭터, 3명 캐릭터 일러스트)을 시각 참조로 사용했다. 이미지 안의 글자는 실행 지시로 취급하지 않았다. 원본 이미지를 제품 texture로 넣거나 외부 서비스에 보내지 않았다.

이전 모델의 큰 단일 원형 몸·긴 분홍 귀·넓은 발을 대체했다. 첫 3D 참조의 큰 가로형 머리, 짧고 별개인 몸통, 옆으로 나오는 작은 팔, 가는 발, 작은 흰 귀를 우선했다. 일러스트의 둥근 눈과 두 흰 반사광, 짧은 눈썹, 작은 코/입, 4개의 사선이 있는 분홍 볼을 함께 반영했다. 서로 다른 참고 이미지의 모든 비율을 동시에 동일하게 재현한 것이라고 주장하지 않는다.

## 구현

- `ChiikawaModel`이 머리/몸통/팔/발/귀/얼굴과 장식 리소스를 소유한다. `ThreeCharacterRenderer`는 조명/카메라/입력/프레임 예약을 담당한다.
- 머리와 몸통은 별개의 spline profile을 회전시킨 LatheGeometry다. 머리는 넓은 볼과 완만한 턱, 몸통은 짧고 둥글게 좁아지는 아랫부분을 가진다. 팔다리/귀는 공유 sphere geometry로 만든다.
- 눈과 볼은 머리 표면에 투영한 곡면 mesh, 눈썹/입/볼 선은 같은 표면을 따라가는 tube다. 정면 이미지 billboard를 사용하지 않는다. 양 눈의 흰 반사광은 두 개씩 만든다.
- 귀는 분홍 inset 없이 흰색이 기본이다. `earColor`는 이제 귀 전체 색상이다. 기존 저장본의 예전 기본 분홍색만 일반 revision 확인/undo 가능한 patch로 흰색으로 반영했다. 다른 속성이나 전체 이력을 직접 덮어쓰지 않았다.
- 몸통 크기는 얼굴을 늘리지 않으며, 몸 높이가 변하면 머리 위치를 함께 옮겨 연결한다. 발은 바닥에 유지한다. 눈/귀 크기, 색, 표정/장식도 기존 문서 schema와 MCP 경로를 유지한다.

## 확인 범위

타입/빌드, 기존 도메인·저장·MCP·배치 테스트에 더해, 몸 크기 최솟값/기본/최댓값에서 머리 연결·발 바닥·얼굴 폭 유지, 표정/눈/귀 편집에서 geometry 재사용·유한 좌표를 검증한다. 브라우저 정면과 측면에서 모델·얼굴 곡면 부착을 직접 확인한다. 닮음에 대한 최종 사용감은 사용자가 평가한다.

새 기본 모델 증거는 `docs/evidence/chiikawa-remodel-front.jpg`와 `chiikawa-remodel-three-quarter.jpg`로 저장한다. 이전 MVP 캡처는 당시 이력이며 현재 모델 모습과 구별한다.
