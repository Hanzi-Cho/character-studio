# 치이카와 비율·표정 레퍼런스 검토 · 2026-10-24

## 범위와 집계 방법

최신 사용자 요구: 얼굴 폭은 몸통보다 아주 조금 넓게, 기본/웃음/슬픔/화남을 포함한 4~6개 표정 시안, 표정만 교체. 인터넷에서 적합한 이미지 50개 이상을 관찰하고 반영한다. 이 기록의 ‘학습’은 **시각 관찰·비교 분석**이며 모델 훈련/파인튜닝을 수행했다는 뜻이 아니다.

3개 공개 미리보기의 **120개 개별 스티커 그림을 직접 화면으로 확인**하고, 치이카와의 얼굴 또는 몸 윤곽이 식별되는 **57개 그림**을 선별했다. A 17개 + B 22개 + C 18개. 집계 단위는 3개 합본 파일 안의 서로 다른 개별 스티커 컷이다. 57개의 별도 원본 파일을 내려받았다고 주장하지 않는다. 같은 그림의 리사이즈·확대·상하 스크롤은 중복 집계하지 않았다. 하치와레·우사기·모몽가 등만 있는 컷은 제외했다. 단체 컷은 치이카와 부분만 참고하고 1개로 센다. 뒷모습은 얼굴 평가에서 제외하고 몸 윤곽에만 사용했다.

## 구현에 반영한 결정과 한계

R02.2 — 기본 모델의 얼굴 최대 폭 : 몸통 최대 폭은 약 **1.08 : 1**. 사용자 요구를 구현 수치로 해석한 목표이며, 원작의 공식 치수나 57장의 통계적 평균이라고 주장하지 않는다. 기존 1.5배 안팎의 큰 머리/작은 몸통과 뚜렷한 턱 경계를 대체한다. 한 개의 연속 lathe 표면, 짧은 팔·발, 흰 둥근 귀, 전체 세로 압축과 낮춘 얼굴 위치를 적용한다. 원근/자세/변형이 있는 그림을 치수 측정에 섞지 않는다.

R03.2 — 기본, 웃음, 슬픔, 화남, 놀람, 졸림 6종. 기본은 둥근 눈+작은 W형 입, 웃음은 위로 휜 감은 눈, 슬픔은 안쪽이 올라간 눈썹+눈물, 화남은 안쪽으로 내려간 눈썹, 놀람은 작은 O형 입, 졸림은 아래로 휜 눈꺼풀로 구분한다. 이미지 복제 대신 자체 곡면 mesh/tube와 자체 SVG 시안을 작성했다. 6종은 사용자 요구에 맞춘 해석이며 원작의 유일한 정답 표정이라고 주장하지 않는다.

표정 patch는 expression 필드만 바꾼다. body geometry buffer/색/비율/귀/장식/이름을 보존한다. 눈썹·입·눈물 그룹의 표시만 교체하고 3D 장면을 다시 만들지 않는다. 실제 Gemini·Claude·GPT 호스트 연결, 표정 애니메이션/리깅, 실제 모바일 기기와 닮음에 대한 사용자 사용감 평가는 이 검토의 완료 범위가 아니다.
